## 🎮 游戏简介

《无宁县志》是一款纯文本交互的古风模拟经营 RPG 网页游戏。游戏以"天"为时间单位，玩家选择一个身份入局，管理体力、金钱、声望等核心资源，通过日常工作、NPC 社交、产业经营、随机事件等方式推动剧情，影响整座县城的命运走向。

游戏数据实时保存于本地，随时可继续你的冒险。

## ✨ 核心特色

### 🎭 三种身份，三段人生

每个身份拥有独特的初始属性、专属技能与被动效果，通关策略截然不同：

| 身份 | 定位 | 专属技能 | 被动效果 | 初始优势 |
|------|------|----------|----------|----------|
| 🏛️ **县丞** | 治理政务 | 巡视乡里（消耗15体力，提升县城属性+声望） | 官威：每日+2声望 | 声望 200 |
| 💰 **商人** | 经营财富 | 风险投资（消耗100金钱+10体力，风险与收益并存） | 精明：工作收益+20% | 金钱 500 |
| ⚔️ **少侠** | 战斗名望 | 闭关修炼（消耗30体力，大幅提升武学修为） | 强健：休息额外+10体力 | 体力上限 120 |

### ⚙️ 丰富游戏系统

<details>
<summary><b>📅 日常循环</b></summary>

- **工作与休息**：每日行动次数有限，需合理安排劳逸结合
- **天气系统**：每日随机天气（晴、雨、雪），天气影响探索掉落与韭菜园产出
- **四季循环**：春夏秋冬更迭，不同季节带来不同事件与机遇
- **健康机制**：体力过低将影响工作效率，须注意休息

</details>

<details>
<summary><b>🏪 深度经济系统</b></summary>

- **市场贸易**：粮草、布匹、茶叶、铁器等商品价格每日随供需波动，考验"低买高卖"的商业头脑
- **产业置办**：购买良田、鱼塘、杂货铺、酒楼、钱庄股份等产业，坐享每日被动收入（受县城经济属性加成）
- **采石场 & 林场**：可升级的资源建筑，持续产出石料、木材等战略资源

</details>

<details>
<summary><b>🌿 韭菜园（特色农业模块）</b></summary>

游戏最具特色的玩法之一。玩家需管理地块的肥力、虫害、品质、成长进度等属性：

- **四种品种**：常规韭菜、快熟韭菜、高香韭菜、耐寒韭菜，各有特点
- **精细化操作**：浇水、施肥、收割，搭配滴灌、自动收割机等设施实现半自动化
- **深加工**：鲜韭加工成"韭菜盒子"可提升售价
- **合作社订单**：与 NPC 建立好感可提升订单质量与倍率
- **市场博弈**：压价/稳价机制、NPC谈价加成，策略纵深极高

</details>

<details>
<summary><b>🌲 养成与成就</b></summary>

- **天赋树**：消耗"阅历"点数提升天赋，永久强化角色（经商之道、能言善辩、强身健体、博闻强识、事半功倍）
- **成就系统**：达成特定条件（如"第一桶金"、"夜雨江湖"）解锁成就并获得丰厚阅历奖励

</details>

<details>
<summary><b>🗣️ NPC 交互系统</b></summary>

- 结识各色人物，通过闲聊、送礼建立羁绊，提升好感度
- 每个 NPC 拥有独特的功能互动（如理发、机关制作、韭菜谈价等）
- 长期互动可解锁隐藏成就与称号
- **注意**：话说多了嗓子会哑，每日聊天次数有上限！

</details>

<details>
<summary><b>🎪 游乐坊（四大娱乐小游戏）</b></summary>

- **💊 长生丹房**：2048 合并玩法，从"药渣"合成至"千年人参"，结算获得金钱或稀有道具
- **🎯 无宁箭馆**：消耗体力射箭，命中率受武学属性影响，赢取声望与彩头
- **🎲 小司赌坊**：三颗骰子押大小，运气与胆量的博弈（遇豹子庄家通吃）
- **🔮 算命小摊**：每日一签，获得当日运势签文（每日限一次）

</details>

<details>
<summary><b>📜 政令系统（县丞专属）</b></summary>

消耗声望颁布持续性政令，深远影响县城发展方向：

| 政令 | 花费 | 每日效果 |
|------|------|----------|
| 休养生息 | 50声望 | 民生+2、治安+1，金钱-10 |
| 严整治安 | 50声望 | 治安+3、声望+2，民生-1 |
| 通商惠工 | 80声望 | 经济+3、金钱+20，治安-2 |
| 兴修文教 | 100声望 | 文化+3、声望+5，金钱-15 |

</details>

<details>
<summary><b>🎯 随机事件系统</b></summary>

- 数百条精心编写的随机事件，涵盖奇遇、危机、机缘等多种类型
- 天气、季节、声望、NPC 好感度等因素影响事件触发概率
- 事件选项产生不同后果，形成蝴蝶效应

</details>

## 🚀 快速开始

### 环境要求

- Node.js v16+
- npm 或 yarn

### 安装与运行

```bash
# 克隆项目
git clone <repository-url>
cd Wuning-County

# 安装依赖
npm install

# 启动开发服务器（通常运行在 http://localhost:5173）
npm run dev
```

### 构建

```bash
# 标准构建
npm run build

# 单文件打包（所有资源内联为一个 HTML 文件）
npm run build:web
```
