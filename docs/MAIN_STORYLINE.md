# 《无宁县志》主线剧情设计

> 版本：1.0 | 日期：2026-03-11

---

## 一、故事背景

### 设定年代
大盛王朝末期，边陲之地「无宁县」

### 地理位置
- 位处王朝边境，三面环山，一面临水
- 是连接中原与塞外的交通要道
- 历来是兵家必争之地

### 社会背景
- 王朝衰落，地方割据势力渐起
- 匪患猖獗，边防松弛
- 商路断绝，民生凋敝
- 各方势力暗流涌动

---

## 二、第一章：初入无宁（第1-10天）

### 剧情目标
玩家以选定身份进入无宁县，通过日常行动了解游戏基础机制。

### 剧情流程

| 天数 | 事件 | 说明 |
|------|------|------|
| 第1天 | **入城** | 玩家选择身份进入无宁县，获得初始资源 |
| 第2天 | **落脚客栈** | 触发NPC「小二」对话，解锁客栈功能 |
| 第3天 | **县衙报到**（县丞专属） | 触发县丞主线，拜见县令 |
| 第3天 | **集市探查**（商人专属） | 触发商人主线，了解市场行情 |
| 第3天 | **偶遇江湖**（少侠专属） | 触发少侠主线结识NPC「墨骨」 |
| 第4-7天 | **熟悉县城** | 自由行动，触发随机事件 |
| 第8天 | **县城现状** | 揭示无宁县的三大危机：匪患、经济、民生 |
| 第10天 | **选择立场** | 第一次主线分支选择 |

### 三大危机数值
| 危机 | 初始值 | 说明 |
|------|--------|------|
| 匪患 | 30-40 | 影响治安和战火风险 |
| 经济 | 20-30 | 影响物价和产业收益 |
| 民生 | 25-35 | 影响NPC互动和政令效果 |

### 关键NPC解锁
- **客栈小二**：提供住宿和情报
- **集市王婆**：商品交易
- **铁匠铺张铁**：装备购置

## 第二章：立足县城（第11-30天）

### 剧情目标
玩家通过经营活动或政务工作，在县城站稳脚跟。

### 分身份剧情

#### 🏛️ 县丞线：官场沉浮
| 天数 | 事件 |
|------|------|
| 第11天 | **县令召见** - 交付第一个政务任务 |
| 第14天 | **巡视四乡** - 消耗体力巡视，触发NPC互动 |
| 第18天 | **粮仓失窃** - 调查案件，选择查办方式 |
| 第22天 | **民间疾苦** - 触发民生事件，决定政令走向 |
| 第25天 | **第一次政令选择** - 休养生息 / 严整治安 / 通商惠工 / 兴修文教 |
| 第28天 | **县丞考核** - 声望达标可获得晋升机会 |

#### 💰 商人线：商海沉浮
| 天数 | 事件 |
|------|------|
| 第11天 | **集市摆摊** - 了解商品价格波动 |
| 第15天 | **第一笔生意** - 低价买入高价卖出 |
| 第19天 | **商队到来** - 触发特殊商品事件 |
| 第23天 | **产业投资** - 可购买第一个产业（良田/商铺） |
| 第26天 | **商业危机** - 选择与商家合作或对抗 |
| 第30天 | **商会邀请** - 加入商会解锁更多功能 |

#### ⚔️ 少侠线：江湖初入
| 天数 | 事件 |
|------|------|
| 第11天 | **武馆试炼** - 提升武学修为 |
| 第14天 | **结交侠客** - 认识NPC「剑侠」 |
| 第18天 | **下山历练** - 触发战斗事件 |
| 第22天 | **匪寨情报** - 获得匪患信息 |
| 第26天 | **第一次行动** - 选择帮助县城或独自行动 |
| 第30天 | **江湖声望** - 根据行为解锁不同江湖称号 |

### 共同事件
- **天气影响**：雨雪天触发特殊事件
- **NPC好感**：与关键NPC好感度达到一定程度解锁专属剧情
- **随机奇遇**：山贼、商人、郎中、道士等随机相遇

## 第三章：风云变幻（第31-60天）

### 剧情目标
县城危机加剧，玩家需要做出重大选择，决定自己的道路。

### 核心事件

#### 战火危机（第35天触发）
```
匪患数值达到60以上时触发
- 山贼夜袭县城
- 玩家需选择：协助防守 / 避而不战 / 趁乱获利
不同选择影响声望、县城状态、后续剧情
```

#### 经济危机（第40天触发）
```
经济数值低于20时触发
- 商路断绝，物价飞涨
- 玩家需选择：开仓放粮 / 稳定物价 / 囤积居奇
不同选择影响金钱、民心、NPC态度
```

#### 民生危机（第45天触发）
```
民生数值低于15时触发
- 流民增多，县城动荡
- 玩家需选择：施粥救济 / 驱逐流民 / 招募流民
不同选择影响人力、治安、声望
```

### 分支剧情

#### 县丞线：官场抉择
- **清官路线**：直言进谏，得罪上级 → 仕途艰难但民心所向
- **贪官路线**：中饱私囊，获得金钱 → 富甲一方但声名狼藉
- **中立路线**：明哲保身 → 平安度日但无甚作为

#### 商人线：商战风云
- **诚信商道**：童叟无因 → 获得「儒商」称号，解锁隐藏商品
- **投机取巧**：囤积居奇 → 短期获利但风险极高
- **官商勾结**：依附权贵 → 获得资源但卷入政治斗争

#### 少侠线：江湖恩仇
- **侠之大者**：保家卫国 → 获得「侠义」称号，解锁江湖声望线
- **独行杀手**：杀手锏任务 → 高风险高回报
- **绿林好汉**：落草为寇 → 开启另一条完全不同的剧情线

## 第四章：最终抉择（第61-90天）

### 剧情目标
县城命运走向最终结局，玩家的选择将决定无宁县的未来。

### 多结局设计

#### 结局一：太平盛世（条件：三项危机均低于20）
```
县丞线：官至知府，造福一方
商人线：成为首富，泽被乡里
少侠线：封妻荫子，江湖传奇
```

#### 结局二：战火纷飞（条件：匪患>80且未阻止）
```
县城被攻破，玩家需选择：
- 死守县城（战死或幸存，取决于防御值）
- 逃难他乡（开启流亡剧情）
- 投靠山贼（开启反派结局）
```

#### 结局三：繁华落幕（条件：经济>80但民生<10）
```
县城富而不仁，最终引发民变
玩家可选择：
- 散尽家财（损失全部财产，换取民心）
- 镇压民变（失去民心，获得短暂和平）
- 远走高飞（遗留骂名）
```

#### 结局四：默默无闻（条件：未触发任何重大事件）
```
玩家安于现状，县城维持在中等水平
平淡是真，也是一种结局
```

#### 隐藏结局：江湖传说（条件：完成所有隐藏任务）
```
需要完成：
- 与所有关键NPC的好感达到最大值
- 收集所有成就
- 触发所有隐藏事件
解锁特殊结局：玩家成为无宁县传说人物
```

## 五、支线剧情

### 永恒支线（贯穿始终）
| 支线 | 说明 |
|------|------|
| 韭菜园剧情 | 合作社建立、品种改良、市场博弈 |
| 游乐坊剧情 | 四大小游戏的高分挑战 |
| NPC个人剧情 | 每位NPC独特的背景故事和互动 |

### 限时支线（特定季节/天气）
| 支线 | 触发条件 |
|------|----------|
| 春节庆典 | 冬季第90天 |
| 雨季洪灾 | 夏季雨天，经济>50 |
| 山贼夜袭 | 匪患>60的夜晚 |
| 朝廷赈灾 | 民生<15时触发 |
