## 第一章：入城事件（第1天）

### 1.1 通用入城事件

#### 事件001：城门守卫
```
【城门】
你来到无宁县城门，灰白的城墙透着几分萧瑟。
守卫上下打量了你一眼："新面孔？进城做工还是赶考？"
/
选项：
A. "在下新任县丞，前来赴任"（需县丞身份）
B. "来做些小本生意"（需商人身份）
C. "游历至此江湖人氏"（需少侠身份）
D. "途经此地歇脚"
```

#### 事件002：初入县城
```
【县城】
踏入县城，街道不长却五脏俱全。
小贩吆喝、书生朗、，铁匠叮当...
/
你注意到城中百姓面色愁苦，议论声传入耳中：
"今年收成又不好..."
"山贼的事儿听说了吗？"
"县令大人也在发愁呢..."
```

### 1.2 身份专属入城事件

#### 事件003：县丞入城（县丞专属）
```
【县衙报到】
你来到县衙，表明身份后衙役恭敬引你入内。
/
县令楼大人正在批阅公文，抬头看向你：
"新来的县丞？很好，无宁县正缺人手。"
"本县有三大难题：匪患、经济、民生。你要好生体会。"
/
他递给你一本《为政之道》：
"好好研读，对你有好处。"
/
获得物品：《为政之道》（使用后+10治理经验）
```

#### 事件004：商人入城（商人专属）
```
【西市】
你来到最热闹的西市，集市繁华。
牙行经纪人刘半城迎上来：
"这位爷面生，做买卖？"
"不瞒您说，最近行情不稳定，压货要慎重。"
/
他递给你一张《市场行情表》：
"先熟悉熟悉。"
/
获得物品：《市场行情表》
```

## 第二章：县城探索（第2-10天）

### 2.1 客栈事件

#### 事件010：住宿
```
【客栈】
"客官，打尖还是住店？"
你花了10文钱，在客栈有了个落脚之处。
/
功能解锁：住宿、休息、打听消息
```

#### 事件011：打听消息（随机）
```
【闲聊】
你和客栈小二闲聊起来。
/
"要说这无宁县，最大的问题就是...
1. 山贼！黑风寨那帮人要粮又要钱；
2. 经济！商路断了，物价涨得厉害；
3. 民生！百姓都快揭不开锅了！"
/
获得县城情报若干
```

### 2.2 街面随机事件

#### 事件020：老人摔倒
```
【街头】
"哎哟！"
一个老人摔倒在路边，手中的米袋滚落一边。
/
选项：
A. 上前扶起（消耗5体力，声望+5，民生感知+1）
B. 假装没看见（声望-5）
C. 派人通知家属（声望+2）
```

#### 事件021：丢失钱袋
```
【捡钱】
你在路边捡到一个钱袋，里面有30文钱。
/
选项：
A. 原地等待失主（声望+10，有几率获得感谢礼）
B. 送往县衙（声望+5，获得县衙奖励20文）
C. 收为己有（金钱+30，声望-10）
```

#### 事件022：街头卖艺
```
【卖艺】
一个江湖艺人在街头表演胸口碎大石。
/
"各位父老，有钱的捧个钱场，没钱的捧个人场！"
/
选项：
A. 打赏10文（声望+3，获得表演心得）
B. 打赏50文（声望+8，获得秘技图谱）
C. 不打赏（无影响）
```

## 第三章：三身份专属事件（第3天）

```
【巡视】
你带人在县城巡视，了解民情。
/
一处民宅前，你听到哭声。
/
"大人！求求您做主啊！"

/
选项：

C. 置之不理（声望-5）
```

### 3.2 商人线事件

#### 事件031：商铺考察
```
【商铺】
你在西市考察商铺。
/
"这位爷，商铺出租！位置绝佳！"
你看了位置，在集市口，人流量大。
/
选项：
A. 租下（消耗100文，获得商铺）
B. 观望（无影响）
C. 砍价（消耗5体力，成功则80文租下）
```

## 第四章：危机事件（第35-45天）

### 4.1 战火危机（35天）

#### 事件050：山贼夜袭
```
【紧急警报】
"报——！山贼夜袭！快关城门！"
/
深夜，城外火光大起，喊杀声由远及近。
/
黑风寨倾巢而出，足有百人之众！
/
楼县令急令："所有人马，务必守住城墙！"
/
你必须做出选择：
/
A. 协助防守
   消耗30体力，参与一线防守
   成功：声望+30，治安+20，县城安全
   失败：受伤，体力-50，声望+10
   
B. 指挥调度
   消耗15体力，在后方指挥
   获得防守经验，治安+10，县城安全
   
C. 暗中行动
   消耗10体力，潜入敌后
   成功：获得重要情报，缴获物资
   失败：暴露身份，声望-10
   
D. 避而不战
   不参与
   县城被破，损失惨重，声望-20
```

### 4.2 经济危机（40天）

#### 事件051：商路断绝
```
【紧急通告】
"朝廷大战，商路被断！"
/
来自京城的商队无法到达，
无宁县与外界的贸易全面中止！
/
粮价一日三涨，百姓慌了神。
/
你必须做出选择：
/
A. 开仓放粮
   消耗100文，开设粥棚
   效果：民生+20，获得"仁商"称号
   
B. 稳定物价
   消耗30声望，强制调控市场
   效果：经济+10，物价稳定
   
C. 囤积居奇
   大量收购粮食
   效果：短期赚500文，但民心-30
   
D. 开辟新路
   消耗40体力，寻找新的商路
   成功：经济+20，获得新商品
   失败：无损失
```

### 4.3 民生危机（45天）

#### 事件052：民变之兆
```
【民变】
"官逼民反！还我粮食！"
/
流民聚集在县衙前，人数已达数百。
/
领头之人高喊："开仓放粮！否则血溅五步！"
/
局面一触即发！
/
你必须做出选择：
/
A. 施粥救济
   消耗80文，设粥棚三日
   效果：民生+25，声望+10
   
B. 镇压暴动
   消耗20体力，命令衙役镇压
   效果：治安+15，民生-15
   
C. 招募流民
   消耗50文+10体力，编入户藉
   效果：民生+10，获得劳动力
   
D. 向上求救
   消耗50声望，八百里加急报朝廷
   效果：朝廷救援在路，结果未知
```

## 第五章：日常随机事件

### 5.1 正面事件

#### 事件060：义诊
```
【义诊】
江湖游医在城中义诊，正好被你遇到。
/
"这位施主，我观你印堂发黑...
啊不是，观你气色不佳，可要诊治一下？"
/
遊医帮你诊脉，送你一副调理药方。
/
获得：体力恢复+20，或随机增益
```

#### 事件061：拾金不昧
```
【归还】
你捡到一袋钱，主动归还失主。
/
失主是城中李员外，感动不已。
/
"壮士高义！这是谢礼，请务必收下！"
/
获得：50文，声望+5，或获得优惠券
```

### 5.2 负面事件

#### 事件070：被碰瓷
```
【碰瓷】
"哎哟！你撞了我！"
一个男子突然摔倒在你面前。
/
"没王法了吗？撞了人还想跑？"
/
围观群众指指点点，你有口难辩。
/
选项：
A. 花钱消灾（30文）
B. 据理力争（消耗声望，获胜概率50%）
C. 报官处理（后续剧情）
```

#### 事件071：遭窃
```
【失窃】
"抓贼啊！"
你被人撞了一下，一摸口袋...
钱袋不见了！
/
选项：
A. 自认倒霉（金钱-20）
B. 追赶小偷（消耗10体力，70%概率追回）
C. 运用智慧（根据能力判定，60%概率抓住）
```

### 5.3 中性事件

#### 事件080：偶遇
```
【奇遇】
你在街上遇到一位奇人。
/
此人仙风道骨，手持拂尘。
/
"贫道观你与无宁县有缘...
此乃天机，不可泄露。"
/
选项：
A. 追问详情（消耗体力，可能获得奇遇）
B. 礼貌告别（获得随机增益）
C. 置之不理（无影响）
```
