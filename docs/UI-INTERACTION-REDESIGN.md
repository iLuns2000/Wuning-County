# 无宁县志新版交互草案

本次是交互方案与演示原型，不接入正式存档。演示的资源消耗、收益与结算不代表最终游戏数值。

## 现有问题

首页把角色状态、主线任务、日常行动、十多个地点入口、背包和完整日志并列展示。人物、建筑、设施又分散到独立页面；另一些大型玩法通过弹窗进入。用户缺少稳定的分类和返回路径。

## 新版信息结构

| 一级入口 | 纳入现有功能 | 主要交互 |
| --- | --- | --- |
| 今日 | 当前任务、工作、休息、身份技能、日常巡防、时间天气、当前事件 | 优先显示当前目标和剩余行动次数；就地反馈结果 |
| 县城 | 小吃街、西市集、游乐街、珍宝阁、柳园、特色建筑、游乐坊、赛鸽、探索、填洞、善行、公告 | 按市井、游赏、游乐、城外筛选地点；进入地点页面，返回保留筛选与滚动位置 |
| 经营 | 产业置办、资源设施、韭菜园地块/设施/加工/订单、贸易 | 先查看资产和待办，再进入经营详情；县城里的对应地点共用同一详情 |
| 人物 | NPC 列表/详情、聊天、送礼、切磋、专属互动；个人资料、天赋、成就 | 人物详情聚合关系与行动；隐藏互动保留原解锁条件 |
| 行囊 | 道具使用、衣装饰品、卷轴和藏珍匣 | 按物品、衣装、收藏切换；购买、打包后可直接定位新物品 |

县城治理作为县丞的常用入口，包括县城指标、政令、官邸、发展路线与外患。商人、少侠首页使用各自专属行动，巡防等共享能力保留。财富榜和其他榜单放在人物页面的榜单入口；说明、反馈、存档与开发者入口放在设置中，开发者入口保留原访问条件。

## 今日布局

1. 顶部：日期天气、任务记录、事件记录、设置。
2. 状态条：身份、体力、银两、声望；点击展开完整状态和负面效果。
3. 当前主线：目标进度、下一步可执行操作、操作成本。
4. 今日行动：工作、休息、巡防、身份技能；次数与禁用原因直接可见。
5. 出门走走：常用地点；正式实现时允许固定常用入口。
6. 日终：结束一天及当日摘要，避免长日志占据首屏。

任务引导只推荐操作，不替用户执行。天气封路、资源不足、次数耗尽、事件阻断均显示具体原因。

## 核心流程

- 老玩家进入：读存档 → 没有界面偏好时选择 → 回到今日；已选择者直接进入。新玩家默认新版，身份选择后进入角色专属引导。
- 任务：今日目标 → 查看条件 → 前往相关行动或地点 → 就地结果 → 回到目标进度。
- 餐饮：县城 → 小吃街 → 品尝就地反馈 / 打包入行囊 → 行囊使用。余额始终可见。
- 社交：人物 → 人物详情 → 选择闲聊/送礼/切磋/专属互动 → 就地反馈关系与资源变化。
- 经营：经营概览 → 地块/订单/资产详情 → 操作 → 更新概览。全流程共享经营数据。
- 过日：手动结束 → 当日小结 → 进入下一日 → 收益与事件。自动过日保持原规则，不增加每次都要点击的确认。
- 事件：必须选择的剧情使用专门事件界面；普通资源反馈不阻断操作。事件激活时沿用当前游戏的动作限制。

## 响应式与层级

- 电脑：左侧固定导航，中间内容；短详情使用右侧抽屉。
- 手机：五项固定底部导航，内容单列；短详情使用底部抽屉；考虑安全区、44px 触控目标。
- 市场、园地、小游戏等复杂玩法使用完整页面，不叠加大型弹窗。
- 页面保留返回路径，抽屉一次仅打开一层；返回恢复上下文。
- 焦点进入抽屉后被限制在内部，关闭恢复触发点；页面切换与结果反馈提供可访问名称。

## 视觉与兼容

暮山紫 #A4ABD6 用于选中、主要操作和品牌标记；雾白承载正文，深紫用于重点文字，青绿表示恢复与经营，暖金表示财富，朱红表示危险。内容区域使用不透明背景。

经典版保持可切回。新版使用独立展示层，共享现有游戏状态与动作函数；不改存档格式、数值、概率、角色限制和解锁条件。
