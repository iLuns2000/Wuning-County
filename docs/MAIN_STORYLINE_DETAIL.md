# 《无宁县志》主线剧情详细设计

> 版本：1.1 | 日期：2026-03-11

---

## 第一章：初入无宁（第1-10天）

### 1.1 第1天：入城

#### 触发条件
- 玩家完成身份选择后自动触发

#### 剧情文本
```
【入城】
你踏入无宁县的城门，灰白的城墙透着几分萧瑟。
城门处的守卫仔细打量了你一眼，既不阻拦也不热情。
/
县城的街道不长，却汇聚了三教九流。
小贩的吆喝声、考生的朗朗书声、铁匠铺的叮当声...
这一切都在告诉你：无宁县到了。
/
根据你选择的身份不同，你会遇到不同的引路人：
```

#### 不同身份的初始引导
| 身份 | 引导者 | 触发事件 |
|------|--------|----------|
| 县丞 | 衙役 | 前往县衙报到，领取官服 |
| 商人 | 牙行经纪人 | 介绍集市规则，提供启动资金 |
| 少侠 | 镖师 | 介绍武馆位置，引荐江湖人士 |

#### 资源获取
- 所有身份：获得50文铜钱作为入城费
- 县丞额外：获得县丞官服（装备）
- 商人额外：获得《无宁商业图鉴》
- 少侠额外：获得《无宁江湖地图》

---

### 1.2 第2天：落脚

#### 触发条件
- 完成入城剧情后

#### 客栈系统解锁
```
【客栈】
你来到城中唯一的客栈"悦来客栈"
/
客栈小二热情迎上："客官，打尖还是住店？"
/
你花费10文钱，在客栈有了个落脚之处。
/
功能解锁：
- 住宿（恢复体力）
- 打听消息（随机获取县城情报）
- 认识旅客（触发随机NPC）
```

#### 第一次自由行动
玩家可选择以下行动之一：
1. **逛街** - 了解县城布局，触发随机NPC
2. **休息** - 恢复体力，触发"好梦"事件
3. **闲逛** - 可能有奇遇

---

### 1.3 第3天：身份专属剧情

#### 🏛️ 县丞专属：县衙报到

**触发条件**：身份为县丞

**剧情文本**：
```
【县衙报到】
你来到县衙，表明身份后，县丞衙役恭敬引你入内。
/
县令楼县令正在批阅公文，抬头看向你：
"新来的县丞？很好，无宁县百废待兴正需要人才。"
/
"本县有三大难题：匪患、经济、民生。你要仔细体会。"
/
楼县令递给你一本《为政之道》：
"好好研读，对你有好处。"
```

**解锁功能**：
- 政令系统（消耗声望发布政令）
- 巡视任务（消耗体力巡视乡里，提升县城属性）
- 驿站公文（收取官方消息）

**获得物品**：
- 《为政之道》（使用后+10治理经验）
- 县丞印信（象征身份）

---

#### 💰 商人专属：集市探查

**触发条件**：身份为商人

**剧情文本**：
```
【集市探查】
你来到最热闹的西市，集市繁华，叫卖声不绝。
/
牙行经纪人刘半城迎了上来：
"这位爷面生，是来我们无宁县做买卖的？"
"不瞒您说，最近行情不稳定，您要稳重抄底啊。"
/
他递给你一张《市场行情表》：
"先熟悉熟悉，等时机对了再下手。"
```

**解锁功能**：
- 市场交易（买卖商品）
- 商业情报（了解价格走势）
- 投资产业（购买商铺/良田/作坊）

**获得物品**：
- 《市场行情表》
- 商人腰牌

---

#### ⚔️ 少侠专属：偶遇江湖

**触发条件**：身份为少侠

**剧情文本**：
```
【偶遇江湖】
你在城中漫步，忽然被人撞了一下。
/
抬头一看，是个身穿补丁衣服的少年，背着把木剑。
/
"抱歉抱歉！"少年连连道歉，"在下墨骨，正在找人比武..."
/
他上下打量了你一番："兄台也是习武之人？"
"近日无宁县来了不少江湖人士，不如一起去武馆看看？"
```

**解锁功能**：
- 武馆修炼（消耗体力提升武学）
- 江湖声望（行侠仗义获取声望）
- 切磋武艺（与NPC战斗）

**获得物品**：
- 木剑（新手武器）
- 《江湖规矩》

---

### 1.4 第4-7天：熟悉县城

#### 自由行动期
这几天玩家可以自由探索，执行日常工作。

#### 推荐行动路线
| 天数 | 推荐行动 | 可触发内容 |
|------|----------|------------|
| 第4天 | 认识NPC | 解锁3-5个基础NPC |
| 第5天 | 探索设施 | 解锁市场、客栈、铁匠铺 |
| 第6天 | 处理日常 | 完成第一个任意任务 |
| 第7天 | 休息调整 | 恢复状态，准备后续剧情 |

#### 随机事件池
```
日常随机事件（这些天会随机触发）：
- 老人摔倒（扶不扶影响声望）
- 丢失钱袋（拾金不昧/据为己有）
- 街头卖艺（打赏获得特殊物品）
- 流浪猫狗（喂养获得好感）
- 书生赶考（资助获得人情）
- 小贩缺斤短两（主持公道）
```

### 1.5 第8天：县城现状

#### 触发条件
- 第8天首次行动时

#### 核心剧情
```
【县城现状】
你在客栈用早膳时，邻桌的谈话引起了你的注意。
/
"听说了吗？黑风寨的山贼又不安分了。"
"边疆战事吃紧，朝廷顾不上咱们这偏远县城。"
"今年收成不好，粮价都涨了三成了。"
/
你意识到：无宁县正处于多事之秋。
/
作为来到无宁县的新人，你决定...
```

#### 县城状态揭示
| 指标 | 当前值 | 说明 |
|------|--------|------|
| 匪患 | 35 | 山贼活动频繁 |
| 经济 | 25 | 商路不畅，物价较高 |
| 民生 | 30 | 百姓生活艰难 |
| 边防 | 50 | 勉强维持 |
| 战火风险 | 20 | 需要关注 |

### 1.6 第10天：选择立场

#### 触发条件
- 第10天行动结束后

#### 核心剧情
```
【选择立场】
经过几天的相处，你对无宁县有了初步了解。
作为 newcomers ，你必须做出选择：
/
A. 协助县令治理县城（县丞路线）
B. 通过商业改善民生（商人路线）  
C. 以武艺守护一方（少侠路线）
/
这个选择将决定你未来的发展方向。
```

#### 选择分支
| 选择 | 效果 |
|------|------|
| A. 协助县令 | 获得10点官方声望，解锁"政令"任务线 |
| B. 商业救民 | 获得50文启动资金，解锁"投资"任务线 |
| C. 以武护民 | 获得一本武学心得，解锁"行侠"任务线 |

## 第二章：立足县城（第11-30天）

### 2.1 县丞路线：官场沉浮

#### 第11天：县令召见
```
【县令召见】
楼县令传来召令，要你前往县衙。
/
"近日有一伙山贼在城外十里坡作案，
你且带人巡视一番，看看能否找到线索。"
/
任务：巡视十里坡
消耗：15体力
奖励：30文 + 5声望 + 民心动向
```

#### 第14天：巡视四乡
```
【巡视四乡】
你带领衙役巡视县城四乡，了解民情。
/
一路上，你遇到不少百姓告状：
- 村东老张的牛被盗
- 村西老王的税被多收
- 村南老李的儿子被抓壮丁
...
/
你一一记录，准备回县衙处置。
```

#### 第18天：粮仓失窃
```
【粮仓失窃】
"不好！粮仓失窃了！"
/
你赶到现场，发现粮仓被挖了个洞，粮食被盗大半。
/
经过调查，线索指向一伙流浪乞儿。
/
选择：
A. 严加追查（消耗20体力，奖励高但放走真凶）
B. 从宽发落（只惩罚首恶，放过从犯，获得民心）
C. 息事宁人（不追查，损失声望）
```

#### 第22天：民间疾苦
```
【民间疾苦】
你深入民间，看到百姓生活的艰辛。
/
有老人病死却无钱医治，
有孩子饿死只剩半块饼，
有女子被卖只为一石粮...
/
你受到极大触动。
/
选择下一步方向：
A. 开仓放粮（消耗50文，获得民心）
B. 上书朝廷（消耗30声望，获得声望）
C. 成立救助（消耗20体力，获得长效效果）
```

---

### 2.2 商人路线：商海沉浮

#### 第11天：集市摆摊
```
【集市摆摊】
你在集市租了个摊位，开始第一次买卖。
/
根据《市场行情表》，你分析：
- 粮草价格处于低位，适合买入
- 布匹供给充足，价格平稳
- 茶叶稀缺，可以囤货
/
选择你要经营的商品：
A. 粮草（风险低，收益稳定）
B. 布匹（中等风险中等收益）
C. 茶叶（高风险高收益）
```

#### 第15天：第一笔生意
```
【第一笔生意】
你完成了入县以来的第一笔大生意。
/
或盆满钵满，或略有亏损，
但你学到了最重要的一课：无奸不商。
```

#### 第19天：商队到来
```
【商队到来】
一支来自京城的商队抵达无宁县。
/
商队带来了稀缺的货物：
- 京城特产的胭脂水粉
- 精美的丝绸锦缎
- 珍稀的药材补品
/
但价格也不菲，你要如何应对？
A. 大量采购（资金风险高）
B. 小量试水（稳妥）
C. 套取情报（不花钱但需要社交）
```

---

### 2.3 少侠路线：江湖初入

#### 第11天：武馆试炼
```
【武馆试炼】
你来到无宁县武馆，参加试炼。
/
武馆教头打量着你：
"想要在江湖立足，先过这三招！"
/
战斗试炼：
- 第一招：基础刀法（测试反应）
- 第二招：步法闪避（测试敏捷）
- 第三招：的气势（测试意志）
/
通过试炼，获得武学修为+20
```

#### 第14天：结交侠客
```
【结交侠客】
在武馆你结识了几位江湖人士：
- 剑侠「君子言」：独行侠客，剑法高强
- 侠盗「MzFeee」：消息灵通，擅长潜入
- 医师「墨骨」：救死扶伤，亦正亦邪
/
每人可进行第一次互动，提升好感
```

## 第三章：风云变幻（第31-60天）

### 3.1 危机触发条件

| 危机 | 触发条件 | 触发天数 |
|------|----------|----------|
| 战火危机 | 匪患>60 | 第35天必定触发 |
| 经济危机 | 经济<20 | 第40天必定触发 |
| 民生危机 | 民生<15 | 第45天必定触发 |

### 3.2 战火危机（第35天）

#### 触发剧情
```
【山贼夜袭】
"报——！山贼夜袭！快关城门！"
/
深夜，城外火光大起，喊杀声由远及近。
/
黑风寨山贼倾巢而出，试图攻占县城。
/
你必须做出选择：
```

#### 选择后果
| 选择 | 效果 |
|------|------|
| A. 协助防守 | 消耗30体力，参与防守战。成功：+30声望/+20治安；失败：受伤 |
| B. 指挥调度 | 消耗15体力，在后方指挥。获得防守经验，治安+10 |
| C. 暗中行动 | 消耗10体力，潜入敌后。成功：获得重要情报/战利品；失败：暴露身份 |
| D. 避而不战 | 不参与。县城损失较大，声望-20 |

---

### 3.3 经济危机（第40天）

#### 触发剧情
```
【商路断绝】
"不好！商队来不了！"
/
朝廷大战，商路被断，无宁县与外界的贸易中止。
/
粮食价格暴涨，百姓慌了神。
/
你必须做出选择：
```

#### 选择后果
| 选择 | 效果 |
|------|------|
| A. 开仓放粮 | 消耗100文，民生+20，获得"仁商"称号 |
| B. 稳定物价 | 消耗30声望，强制调控，经济+10 |
| C. 囤积居奇 | 短期赚大钱，但民心-30（风险极大） |
| D. 开辟新路 | 消耗40体力，寻找新商路。成功：经济+20；失败：无损失 |

### 3.4 民生危机（第45天）

#### 触发剧情
```
【民变之兆】
"官逼民反！还我粮食！"
/
流民聚集在县衙前，要求开仓放粮。
/
局面一触即发，你必须做出选择：
```

#### 选择后果
| 选择 | 效果 |
|------|------|

| B. 镇压暴动 | 消耗20体力，治安+15，民生-15 |

## 第四章：最终抉择（第61-90天）

### 4.1 结局判定

#### 触发条件
- 县城状态和玩家选择共同决定

#### 结局类型

**结局A：太平盛世**
```
触发条件：
- 经济>50
- 治安>50  
- 民生>40
- 战火风险<30
/
结局文本：
在你的治理下，无宁县逐渐繁荣。
商路重新开通，百姓安居乐道，山贼也被压制。
楼县令上书朝廷，为你请功...
你将成为无宁县历史上最受爱戴的县丞/首富/侠客。
```

**结局B：战火纷飞**
```
触发条件：
- 战火风险>80且未阻挡
/
结局文本：
县城被山贼攻破，大火三日不灭。
你带着少数幸存者逃离，在废墟上重建家园...
这是一个关于失去与重生的故事。
```

**结局C：繁华落幕**
```
触发条件：
- 经济>70
- 民生<15
/
结局文本：
县城富甲一方，但你发现百姓已离心离德。
在一个月黑风高之夜，民变爆发...
你在混乱中逃离，留下无尽的悔恨。
```

**结局D：默默无闻**
```
触发条件：
- 未触发任何重大危机事件
- 县城状态在30-50之间
/
结局文本：
你的任期结束，县城依然如故。
没有功成名就，也没有遗臭万年。
这就是平凡的人生吧。
```

**结局E：江湖传说（隐藏）**
```
触发条件：
- 完成所有NPC个人剧情
- 收集所有成就
- 获得所有称号
/
结局文本：
你已成为无宁县的传奇。
百姓传颂着你的故事，
江湖上流传着你的传说。
多年后，有人问你：无宁县最好的时光是什么时候？
你笑着说：每一天。
```
