## 三、数值计算公式

### 3.1 工作收益

```
基础收益 = 10 + 能力 × 0.5
县丞加成 = 基础收益 × 1.2（政务熟练）
商人加成 = 基础收益 × 1.3（经营活动）
少侠加成 = 基础收益 × 1.1（修炼强化）
```

### 3.2 产业收益

```
日收益 = 基础价格 × 产业等级 × (1 + 经济/200)
```

### 3.3 声望获取

| 行动 | 基础声望 | 条件加成 |
|------|----------|----------|
| 巡视乡里 | +5 | 治安低时+3 |
| 完成政令 | +10 | 持续效果+5/天 |
| 帮助百姓 | +3 | 民生低时+5 |
| 行侠仗义 | +8 | 击败山贼+10 |

### 3.4 体力消耗

| 行动 | 基础消耗 | 说明 |
|------|----------|------|
| 日常工作 | 20 | 获取金钱和经验 |
| 休息恢复 | 0 | 基础恢复50点 |
| 特殊行动 | 15-30 | 巡视、战斗等 |
| 少侠修炼 | 30 | 闭关修炼消耗大 |

## 四、事件触发条件

### 4.1 主线事件触发

| 事件 | 触发天数 | 触发条件 | 前置事件 |
|------|----------|----------|----------|
| 入城 | 第1天 | 无 | - |
| 身份剧情 | 第3天 | 无 | 入城完成 |
| 县城现状 | 第8天 | 无 | 身份剧情完成 |
| 立场选择 | 第10天 | 无 | 县城现状完成 |
| 战火危机 | 第35天 | 匪患>60 | 第30天前完成立场选择 |
| 经济危机 | 第40天 | 经济<20 | 同上 |
| 民生危机 | 第45天 | 民生<15 | 同上 |
| 最终结局 | 第90天 | 无 | 所有前置完成 |

### 4.2 随机事件权重

```
事件类型权重：
- 正面事件：30%
- 中性事件：40%  
- 负面事件：30%

影响因素：
- 天气：雨雪天增加负面事件概率10%
- 季节：冬季增加负面事件概率5%
- 县城状态：民生<20增加负面15%
```

### 4.3 NPC事件触发

```
触发公式：
基础概率 = 5% + 好感度/100 × 10%
特殊情况：
- 首次互动：100%触发
- 特殊日期（如节日）：触发率翻倍
- 隐藏剧情：好感度80+时概率触发
```

## 七、公式汇总

### 7.1 战斗伤害

```
伤害 = 基础伤害 × (1 + 武学修为/100) × (1 + 武器加成)
暴击率 = 5% + 暴击属性/100
闪避率 = 5% + 敏捷属性/100
```

### 7.2 市场价格波动

```
基础价格 = 设定价格
波动系数 = (50 + 随机(-20~+20) + 经济修正) / 100
实际价格 = 基础价格 × 波动系数
```

### 7.3 政令效果持续

```
每日效果 = 基础效果 × (1 + 声望/1000)
持续时间 = 3天 + 声望/100 (天)
```
