## 第一部分：世界观设定

### 一、时代背景

- **设定年代**：大盛王朝末期
- **地理位置**：边陲之地「无宁县」，三面环山，一面临水，连接中原与塞外的交通要道，兵家必争之地
- **社会背景**：王朝衰落、地方割据势力渐起、匪患猖獗、边防松弛、商路断绝、民生凋敝

### 二、核心势力

| 势力 | 简介 |
|------|------|
| **县衙** | 以楼县令为核心的官方治理机构 |
| **无宁卫** | 夏君统领的江湖治安组织 |
| **江湖势力** | 各路侠客、门派、游医等 |
| **商业联盟** | 各商铺、酒楼、戏院等 |

### 三、玩家身份线

| 身份 | 定位 | 发展方向 |
|------|------|----------|
| 县丞 | 官场 | 政务、巡视、政令 |
| 商人 | 商海 | 贸易、投资、商会 |
| 少侠 | 江湖 | 武馆、江湖声望、行侠仗义 |

### 四、三大危机数值

| 危机 | 初始值 | 影响 |
|------|--------|------|
| 匪患 | 30-40 | 治安、战火风险 |
| 经济 | 20-30 | 物价、产业收益 |
| 民生 | 25-35 | NPC互动、政令效果 |

### 五、多结局设计

- 太平盛世 / 战火纷飞 / 繁华落幕 / 默默无闻 / 江湖传说
