# 《无宁县志》游戏宣传文案

## 主宣传文案（完整版）

**《无宁县志》——你不是旁观者，你就是这座县城的命运。**

一县风雨，三种人生。
你可以是运筹帷幄的县丞，在民生与治安间艰难平衡；
也可以是精于算计的商人，在风云市场里低买高卖；
还可以是快意江湖的少侠，在切磋与奇遇中闯出名声。

在这里，你会经营产业、培育赛鸽、种出一园好韭；
你会结识脾气迥异的 NPC，送礼、闲聊、谈价，甚至一言不合就切磋；
你也会在灾情与战火逼近时，做出影响整座无宁县的决定。

**每一次“过一天”，都是一次命运结算。**
是富甲一方，还是名满江湖？
是守住县城，还是任其沉沦？

现在入局，写下属于你的无宁县志。

## 短视频/社媒短句版

- 一天一抉择，一县一人生。来《无宁县志》，把你的名字写进县志。 
- 经营、社交、切磋、赛鸽、战火治理——这是会“长大”的古风模拟 RPG。 
- 你以为在玩经营？其实你在决定一座县城的命运。

## 应用商店简介版（100字左右）

《无宁县志》是一款古风文字模拟经营 RPG。你可扮演县丞、商人或少侠，在日常经营、市场交易、NPC 互动、赛鸽养成与战火治理中推进剧情。游戏拥有任务链、成就系统与多种小游戏，支持本地存档与导入导出。每一次“过一天”，都会改写你的结局。
