# 无宁县县城四维影响路径分析（经济 / 治安 / 文化 / 民生）

## 1. 四维指标分别会受到什么影响

### 经济（Economy）
- 正向来源：
  - 县丞政令“通商惠工”（每日经济+3）
  - 县丞任务行动“鼓励商贸”（经济+5）
  - 商人任务行动“垄断市场”（经济+5）
  - 通用随机事件“商机出现-投资”（经济+5）
  - 角色事件“县城规划-大力发展商业”（经济+10）
- 负向来源：
  - 挑战事件“强盗来袭-加强防御”（经济-5）
  - 挑战事件“自然灾害-祈祷”（经济-10）

### 治安（Order）
- 正向来源：
  - 县丞政令“严整治安”（每日治安+3）
  - 县丞政令“休养生息”（每日治安+1）
  - 县丞任务行动“严厉执法”（治安+5）
  - 少侠任务行动“夜间巡逻”（治安+5）
  - 通用事件“强盗来袭-组织抵抗”（治安+10）
- 负向来源：
  - 县丞政令“通商惠工”（每日治安-2）

### 文化（Culture）
- 正向来源：
  - 县丞政令“兴修文教”（每日文化+3）
  - 县丞任务行动“宣讲教化”（文化+3）
  - 商人技能成功分支“名望方案”（文化+2）
  - 少侠技能成功分支“开馆授徒”（文化+2）
  - 事件“节日庆典-参与庆典”（文化+5）
  - 商人专属事件“开设分店-资助县学”（文化+3）
  - 少侠专属事件“江湖悬赏令-公开讲武”（文化+2）
- 负向来源：
  - 当前核心系统中，文化缺少直接的“稳定负向日常扣减”政令；更多是间接受随机事件与危机链影响。

### 民生（Livelihood）
- 正向来源：
  - 县丞政令“休养生息”（每日民生+2）
  - 县丞任务行动“宣讲教化”（民生+3）
  - 商人任务行动“开仓放粮”（民生+2）
  - 通用事件“县城集市-前往集市”（民生+2）
  - 通用事件“自然灾害-组织救援”（民生+5）
  - 县丞专属事件“县城规划-改善民生福利”（民生+10）
- 负向来源：
  - 县丞政令“严整治安”（每日民生-1）
  - 挑战事件“自然灾害-祈祷”（民生-20）

## 2. “三种角色”是否都能影响四维？

结论：**都能影响，但“效率”和“稳定性”不对称**。

- 县丞：
  - 唯一拥有政令系统与“巡视乡里”稳定入口，且可覆盖四维（经济/治安/文化/民生）。
  - 是最像“系统级调参”的角色，适合平衡盘面。

- 商人：
  - 对经济最强（初始资金高、经济相关行动多），也能通过“名望方案/资助县学”补文化，通过“开仓放粮”补民生。
  - 对治安主要依赖通用事件，缺少稳定高频、可控的专属治安增益手段。

- 少侠：
  - 对治安最直接（巡逻、缉凶），可通过“开馆授徒/公开讲武”拉文化。
  - 对经济与民生缺少专属稳定增长按钮，更多依赖通用事件或与其他系统联动。

## 3. 能否“保持平衡”？

结论：**可以，但最佳解是“县丞主控 + 另外两角色补短板”**。

- 系统设计本身存在显式权衡：
  - “通商惠工”拉经济但掉治安；
  - “严整治安”拉治安但掉民生。
- 因此平衡打法通常是“对冲组合”而非单线拉满：
  - 经济冲刺期：通商惠工 + 事件补治安；
  - 稳定期：休养生息兜底民生治安；
  - 长线声望期：兴修文教叠文化与声望。

此外，县城发展路线里还有“综合治理”路线，明确给四维统一增益与减损缓冲，属于后期平衡器。

## 4. 哪些维度在某些角色下“没有路径提升”或“路径明显不足”

严格说“完全没有路径”较少，但存在“稳定可控路径不足”：

1. 商人 → 治安：
   - 缺少像县丞政令/少侠巡逻那样稳定、可重复的专属治安提升动作。
   - 主要依赖随机事件或间接收益，控盘能力弱。

2. 少侠 → 经济：
   - 少侠专属内容偏战斗与声望，经济提升更多来自通用事件/奖励，不是强项。

3. 少侠 → 民生：
   - 少侠专属路径对民生直接加成较少，更多是治安与文化侧贡献后带来的间接改善。

4. 文化负向调节：
   - 文化上行路径很多，但“主动压文化换别的收益”的策略开关较少，导致文化更像长期只涨不控的维度。

## 5. 建议与解决方案：如何“稳定身份的可控路径”

下面给一套可落地、改动成本可控的平衡方案，目标是：
- 每个角色都至少有 2 条“可重复、低随机、可预期”的县城四维干预手段；
- 每条手段都带有明确代价，避免同质化和无脑最优解。

### 5.1 商人：补“治安”稳定入口

问题：商人对治安缺少稳定专属手段，主要靠随机事件。

建议新增两个商人专属行动（任选其一先做 MVP）：

1. **商会巡防（每日 1 次）**
   - 消耗：金钱 80 + 体力 10
   - 效果：治安 +3、经济 +1
   - 副作用：声望 -1（被质疑“商人干政”）
   - 设计意义：让商人能“花钱买稳定”，符合角色气质。

2. **雇佣镖队护市（持续 3 天 Buff）**
   - 启动消耗：金钱 200
   - 每日效果：治安 +2，若触发“强盗类”事件则额外减伤 30%
   - 设计意义：把商人的“资金优势”转化为“风险对冲能力”。

### 5.2 少侠：补“经济 / 民生”稳定入口

问题：少侠对经济与民生缺少可持续、可规划的增益回路。

建议新增两个少侠专属行动：

1. **护送商队（每日 1 次）**
   - 消耗：体力 20
   - 效果：经济 +3、治安 +1、金钱 +30
   - 失败机制：按能力判定，失败时仅获得金钱 +10 且体力照扣
   - 设计意义：少侠可通过“武力服务”稳定带动经济。

2. **义诊护民（每日 1 次）**
   - 消耗：体力 15 + 金钱 20
   - 效果：民生 +3、声望 +5
   - 设计意义：把“行侠仗义”转换为可量化的民生改善路径。

### 5.3 县丞：维持“全局调参”，但降低操作门槛

问题：县丞虽全能，但对新手而言，政令对冲复杂度高。

建议增加“治理模板”快捷按钮（不改底层政令，仅做组合封装）：

- **维稳模板**：自动推荐“休养生息 + 严整治安”并提示净变化；
- **发展模板**：自动推荐“通商惠工 + 治安补偿行动”；
- **文教模板**：自动推荐“兴修文教 + 民生兜底行动”。

设计意义：
- 不改变高手的自由度；
- 显著提升普通玩家对“平衡盘面”的可控感。

### 5.4 给“文化”增加负向调节阀（防止单向膨胀）

建议新增一条可选政令（非必须常驻）：

- **务实兴业**
  - 每日效果：经济 +2、文化 -1
  - 场景：经济冲刺期，允许玩家牺牲部分文化换增长速度。

设计意义：文化从“只涨不控”变成“可被策略性取舍”的维度。

### 5.5 一套“平衡性验收标准”（建议用于后续调参）

可以用以下指标来验证“稳定可控路径”是否达标：

1. **角色覆盖度**：每个角色至少能稳定提升四维中的 3 项，且每项至少 1 条非随机路径；
2. **回合可预期性**：关键行动的期望收益波动不超过 ±40%；
3. **代价一致性**：同量级增益在不同角色间的“资源成本”差异不超过 25%；
4. **反向调节能力**：四维中至少 3 项具备“可主动下调”的策略开关；
5. **危机恢复时间**：任一维度跌破 20 后，合理操作应在 6~10 天内拉回到 40+。

---

如果只做第一期（最低成本版本），优先级建议：

1. 先做“商会巡防”（补商人治安短板）；
2. 再做“护送商队”（补少侠经济短板）；
3. 最后补“务实兴业”（补文化反向调节）。

这样能最快把“三角色都可控”这件事做实，同时尽量不动现有主循环。
